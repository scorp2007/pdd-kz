# ПДД Казахстана

Справочник по Правилам дорожного движения Республики Казахстан: официальный текст, дорожные знаки, разметка, словарь терминов и разборы простым языком.

**Открыть сайт → https://scorp2007.github.io/pdd-kz/**

## Что внутри

Один самодостаточный файл `index.html` — весь текст, все изображения, шрифты и логика упакованы внутрь. Ни сборки, ни сервера, ни зависимостей: файл можно открыть локально двойным кликом, и он будет работать так же.

### Официальный текст

| Документ | Источник |
|---|---|
| Правила дорожного движения, 26 глав | Приказ МВД РК от 30 июня 2023 года № 534 (рег. № 33003) |
| Приложение 1. Дорожные знаки — 320 знаков | там же |
| Приложение 2. Дорожная разметка | там же |
| Основные положения по допуску транспортных средств | там же |

| Ответственность за нарушения ПДД | КоАП РК от 5 июля 2014 года № 235-V, глава 30 |
| Первая помощь и состав аптечки | приказы Минздрава РК № ҚР ДСМ-269/2020 и № ҚР ДСМ-118/2020 |

### Просто о главном

24 темы своими словами — скорость, полосы, обгон, перекрёстки, светофор, регулировщик, остановка и стоянка, буксировка, первая помощь, штрафы и другие. Это пересказ, а не нормативный текст: у каждой темы есть ссылка на соответствующие пункты официального текста, и наоборот.

### Как этим пользоваться

* Поиск по всем документам, знакам и терминам — клавиша `/`
* Клик по любому номеру знака, разметки или пункта в тексте открывает его
* Термины из главы 1 подсвечены — определение показывается при наведении
* Живой пересчёт МРП в тенге в разделе штрафов
* Тёмная и светлая темы, работает на телефоне

## Обновление

Файл `index.html` собирается из исходных данных отдельно и кладётся сюда целиком. Чтобы обновить сайт, достаточно заменить его и запушить в `main` — GitHub Pages пересоберётся сам.

## Оговорка

Юридическую силу имеет только официально опубликованный текст на [adilet.zan.kz](https://adilet.zan.kz/rus/docs/V2300033003). Раздел «Просто о главном» — пояснения автора, а не нормативный документ.
