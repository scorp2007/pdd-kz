# ПДД Казахстана

Справочник по Правилам дорожного движения Республики Казахстан: официальный текст, дорожные знаки, разметка, штрафы и разборы простым языком.

**Открыть сайт → https://scorp2007.github.io/pdd-kz/**

## Как устроен сайт

Статический сайт из 436 отдельных страниц — по одной на каждую главу, тему и дорожный знак. Каждая страница отдаётся уже собранной, поэтому открывается мгновенно и полностью читается поисковиками.

| | |
|---|---|
| Вес страницы | 9–12 КБ в сжатом виде |
| Общий CSS и JS | 16 КБ, кэшируются после первой страницы |
| Картинки | отдельные webp, грузятся только те, что видно на экране |
| Поиск | индекс подгружается лениво, только когда им пользуются |

Адреса человекочитаемые и постоянные:

```
/prosto/skorost-dvizheniya/
/dorozhnye-znaki/3.24/
/pravila/glava-12-ostanovka-i-stoyanka/
/shtrafy-koap/statya-592-prevyshenie-ustanovlennoy-skorosti-dvizheniya/
```

У каждой страницы свои `title` и `description`, канонический адрес, Open Graph и разметка хлебных крошек schema.org. Есть `sitemap.xml` и `robots.txt`.

### Просто о главном

23 темы своими словами — скорость, полосы, обгон, перекрёстки, светофор, регулировщик, остановка и стоянка, буксировка, первая помощь, штрафы и другие. Это пересказ, а не нормативный текст: в каждой теме есть ссылки на конкретные пункты официального текста, и наоборот — рядом с пунктом стоит ссылка на разбор.

### Возможности

* Поиск по всем документам, знакам и терминам — клавиша `/`
* Номера знаков, разметки и пунктов в тексте кликабельны
* Термины из главы 1 подсвечены и ведут в словарь
* Живой пересчёт МРП в тенге в разделе штрафов
* Отметки о прочитанных главах, размер текста, тёмная и светлая темы
* Работает на телефоне

## Сборка

Содержимое репозитория генерируется скриптом из исходных данных: один и тот же код собирает и этот многостраничный сайт, и версию «всё в одном файле» для чтения офлайн. Готовые файлы кладутся в репозиторий целиком, поэтому GitHub Pages ничего не собирает — достаточно запушить в `main`.

## Оговорка

Юридическую силу имеет только официально опубликованный текст на [adilet.zan.kz](https://adilet.zan.kz/rus/docs/V2300033003). Раздел «Просто о главном» — пояснения автора, а не нормативный документ.
